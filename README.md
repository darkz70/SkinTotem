# SkinTotem

Fabric mod for Minecraft 1.21.1 that replaces the Totem of Undying texture with a mini-player figure.

## Features
- Rename a Totem of Undying on an anvil to any player's nickname.
- Automatically fetches skins from Mojang, Ely.by, and TLauncher.
- Generates a 16x16 mini-player texture dynamically.
- Compatible with Android launchers (FCL/PojavLauncher).
