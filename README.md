## 🇷🇺 Русский

Fabric мод для Minecraft 1.21.1.
Заменяет текстуру Тотема Бессмертия на фигурку из скина игрока.

### Что нового в v2.5
- Улучшена система рендеринга тотема в руках игрока.
- Оптимизирована загрузка скинов из различных источников.
- Добавлена поддержка динамического обновления текстуры при переименовании.
- Исправлены ошибки кэширования скинов.

### Как использовать
- Наковальня: Переименуй тотем → напиши ник или ссылку на скин.
- Команда: Держи тотем в руке и пиши:
  /totem Notch
  /totem https://example.com/skin.png

### Источники скинов
1. Mojang (Лицензия)
2. Ely.by
3. TLauncher
4. Прямая URL-ссылка

<a name="english"></a>
## 🇺🇸 English

Fabric mod for Minecraft 1.21.1.
Replaces the Totem of Undying texture with a figure based on the player's skin.

### What's New in v2.5
- Improved totem rendering system in player's hands.
- Optimized skin fetching from various sources.
- Added support for dynamic texture updates upon renaming.
- Fixed skin caching issues.

### How to Use
- Anvil: Rename the totem → enter a player's nickname or a direct skin link.
- Command: Hold the totem in your hand and type:
  /totem Notch
  /totem https://example.com/skin.png

### Skin Sources
1. Mojang (Premium)
2. Ely.by
3. TLauncher
4. Direct URL link
